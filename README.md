# LiteClient Website

The official website for LiteClient — a fast, native, and privacy-first REST API client for VS Code.

## 🚀 Vision
LiteClient is built for developers who are tired of bloated API clients. No accounts, no telemetry, no cloud nonsense. Just a blazing fast, local-first tool that stays out of your way.

## 🛠 Tech Stack
- **Vanilla HTML/CSS/JS**: Blazing fast performance with zero dependencies.
- **One-Pager Design**: Ultra-minimalist UX focusing on the core value proposition.
- **Theme Aware**: Supports system dark/light modes with a manual override toggle.
